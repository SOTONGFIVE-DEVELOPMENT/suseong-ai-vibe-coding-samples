## 별도 복사본 준비

두 번째 날에는 06 로컬 최종 앱을 완성한 뒤 선택 활동으로 05 정상본 ZIP을 별도 폴더에 풀고 설치를 미리 마칩니다. 서버를 중지하고 `npm run prepare-transfer -- --copy` → `npm run dev` 순서로 가상 시설 3건을 준비합니다. 화면 제목·출처·배지가 가상 자료로 바뀌었는지 확인하고 `items`를 수정합니다. 원본 기관 이름·수집 시각·전체 건수·응답 지문을 가상 목록에 붙이지 않습니다. 가상 전이 중에는 API 가져오기 영역이 표시되지 않습니다.

이 선택 응용에서는 바꾼 조건 하나만 아래 시험으로 평가합니다. 필수 도서관 최종 앱의 이름·지역·유형 AND·URL 복원·전화 링크 검증은 05·06 CHECKLIST에서 별도로 모두 수행합니다.
