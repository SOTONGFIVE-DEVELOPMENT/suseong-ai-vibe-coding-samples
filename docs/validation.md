# 실습 정상본 검증 근거

아래 기존 설치·HTTP·ZIP·스크린샷 근거는 **실제 공개 저장 예제로 교체하기 전의 가상 A/B/C 버전** 기록입니다. 과거 검증을 현재 자료의 검증으로 읽지 마세요. 현재 교체 라운드의 검증 범위는 다음 절에 별도로 기록합니다.

## 실제 공개 저장 예제 교체 라운드

검증 진행일: **2026-10-04 (한국 시간)**. 실제 API 응답의 원본 공개 필드에서 선정한 3건을 여섯 단계에 같은 내용으로 보관했습니다. 원본 수집 시각은 2026-10-04 19:17:37 한국 시간이며 기관 기준일과 이 PC 재생·저장 시각을 분리합니다. Node.js **22.23.3**으로 루트 `npm run check`와 각 단계의 `npm run check`를 실행했습니다. 여섯 단계 테스트 **32개**(1·1·4·4·11·11)가 모두 통과했고 Next.js **16.3.8** 빌드 6개도 성공했습니다. 경고는 없었습니다. 실제 키를 읽거나 외부 API를 호출하지 않았습니다.

이번 검증은 실제 공개 필드 보존, 사월 검색 1건·0건·초기화 3건, 수성구 2건·중구 1건·작은도서관 AND 1건, 저장 응답과 원본 수집 메타 보존, 직접 `header/body` 및 `response` 포장 형식, 모의 전체 페이지 건수 검증·정확 중복 제거·ID 충돌 거부, 오류 시 정상 파일 보존을 포함합니다. 루트 검사는 각 단계 성공 기준과 복구 seed, API 명세·응답의 독립 ZIP용 사본이 정본과 일치함을 확인합니다.

현재 자료로 새 ZIP을 만드는 작업과 공개 다운로드 갱신은 별도 배포 작업입니다. 이 교체 라운드에서 Windows PC, 학생 본인의 인증 API 호출, 새 자료의 브라우저 클릭·레이아웃은 미확인입니다. 아래 과거 버전의 HTTP·스크린샷 결과를 현재 버전에 다시 측정한 것으로 적지 않습니다.

## 교체 이전 버전의 보존 근거

검증일: **2026-10-04 (한국 시간)**. 실행 환경은 macOS, Node.js **22.23.3**, Next.js **16.3.8**, React **19.3.0**, Tailwind CSS **4.3.3**, daisyUI **5.7.47**입니다. 기본 설정은 DATA_MODE=sample이며 실제 인증키는 사용하지 않았습니다.

## 독립 설치·테스트·빌드

각 단계 폴더에서 `npm ci`와 `npm run check`를 실행했습니다. check는 `npm test`와 `npm run build`를 순서대로 실행합니다.

| 단계 | 테스트 통과 | Next 빌드 | 확인 범위 |
|---|---:|---|---|
| 00 시작 | 1/1 | 성공 | 단계·가상 자료 계약, 시작 화면 컴파일 |
| 01 화면 | 1/1 | 성공 | 단계·가상 자료 계약, 빈 표 화면 컴파일 |
| 02 자료 | 4/4 | 성공 | JSON 조회·검색 함수·누락 값·저장 재조회·잘못된 갱신 보존 |
| 03 검색 | 4/4 | 성공 | 이름 3→1→0→3, 지역·유형 AND 함수, 저장 보존 |
| 04 API | 9/9 | 성공 | sample 가져오기·모의 live 페이지 수집·인증/형식/시간 초과 거부·중복·local origin |
| 05 변경 | 9/9 | 성공 | API 검증과 파일 보존, 지역·유형 조건·누락 값 |

합계 28개 테스트를 통과했습니다. 코드를 수정한 뒤에는 그 단계의 check를 다시 실행했습니다. 04/05에는 Next가 내부 request.url을 localhost로 만드는 동작과 실제 Host=127.0.0.1을 함께 검사하는 회귀 조건이 들어 있습니다. local이 아닌 Host나 외부 Origin은 허용하지 않습니다.

## 실제 Next 서버의 HTTP 동작

정상본을 따로 임시 복사해 `127.0.0.1:3034`에서 Next 프로덕션 서버로 실행한 뒤 Node로 HTTP 요청을 보내 확인했습니다. 원본 정상본의 자료 파일은 변경하지 않았습니다.

- 같은 local Origin의 `/api/import` 성공 요청: HTTP 200, 가상 3건 저장, `meta.dataMode=sample`.
- 시간 초과·형식 오류·인증 오류의 교육용 재현: 각각 HTTP 502, 이전 저장 파일의 전체 내용 동일.
- 외부 Origin 요청: HTTP 403, 이전 파일 유지.
- `/api/libraries?q=도서관 B`: count=1.

위 결과는 HTTP와 파일 동작을 확인한 근거입니다. 실제 Codex 사용 화면과 브라우저에서 클릭하고 입력한 근거는 [Codex 따라 하기](codex-walkthrough.md)에 기록합니다.

## 패키지 구성 확인

루트에서 `npm run check`를 실행해 6단계의 manifest, lockfile, 독립 실행 파일, MIT 라이선스를 확인했습니다. 기본 가상 자료 3건과 도서관 B의 빈 주소, 127.0.0.1 실행 주소도 이때 함께 확인했습니다. 04/05의 API 명세와 가상 응답 사본은 루트 정본과 바이트 단위로 일치합니다. 각 단계 README, PROMPTS, CHECKLIST의 로컬 링크는 모두 그 단계 폴더 안에서 열립니다.

각 단계의 `.gitignore`가 node_modules, .next, .env.local, 임시 파일, 복구 백업은 제외하고 `.env.example`은 포함하는 것을 확인했습니다.

2026-10-04에 ZIP 8개를 실제로 만들어 각 ZIP의 CRC 무결성, 경로, 의존성/비밀 파일 제외 여부를 검사했습니다. 모든 단계 ZIP에 lockfile과 `.gitignore`가 포함됩니다. STEP-04 ZIP을 새 임시 폴더에 풀어 Node.js 22에서 `npm ci`와 `npm run check`를 실행했고, 테스트 9개와 Next 빌드가 통과했습니다. 공개 다운로드 파일의 크기, SHA-256, 원본 Git 커밋은 실습 사이트의 `/downloads/course.json`과 `SHA256SUMS.txt`에 기록합니다.

실제 브라우저 검증은 [Codex 따라 하기](codex-walkthrough.md)에 출처와 스크린샷 11장으로 기록했습니다. 최신 조회 응답만 화면을 바꾸도록 한 보강은 별도 검토에서 느린 초기 응답, 오래된 오류, effect cleanup 이후 응답 순서를 제어해 다시 확인했습니다.

## 미확인 범위

Windows PC의 실제 설치와 실행, 본인 인증키로 하는 공공데이터포털의 실전 API 호출, 실제 참여자의 독립 수행률과 수업 시간 준수 여부는 아직 확인하지 않았습니다. 공식 API 명세의 endpoint, 항목, 페이지 규칙은 [API 명세](api-spec.md)에 적힌 출처에서 확인했습니다. 가상 응답이 성공했다고 해서 실전 API 인증도 성공한 것으로 보지 않습니다.
