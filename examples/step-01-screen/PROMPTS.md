# P2 첫 화면의 정상 결과 확인 — Codex 요청문

출발 상태: 01은 P2의 완성 정상본입니다. 직접 P2를 만들 때는 00 시작본의 별도 복사본에서 시작합니다. 이 폴더에서는 기존 화면을 다시 만들 필요가 없습니다.

## 정상본을 읽고 확인하기

```text
현재 구현에서 P2의 제목, 5개 열, 빈 자료 안내가 어디에 있는지 설명해줘. 파일을 수정하지 말고 README의 성공 기준을 화면에서 확인할 순서를 알려줘. 다음 P3에서 JSON 자료를 연결할 때 필요한 파일 → 서버 → 화면의 흐름도 짧게 설명해줘.
```

## P2 — 직접 제작할 때만 (00 복사본에서)

```text
이 시작 프로젝트의 별도 복사본에 공공도서관 정보 조회 화면을 만들어줘. 제목과 도서관명·지역·유형·주소·데이터 기준일 열만 있는 빈 표를 보여줘. 아직 자료를 연결하지 말고 데이터가 없다는 안내를 보여줘. 실제 기관 정보를 지어내지 마. 변경 파일과 확인 방법을 알려줘.
```

## 결과 검증 요청

```text
현재 구현을 읽고 이미 된 항목과 추가할 항목을 구분해줘. README와 CHECKLIST의 해당 활동 기준마다 실행 폴더, 자료 종류, 입력, 기대 결과, 실제 결과를 비교해줘. 파일을 바꿨다면 변경 파일을 알려주고 npm test와 npm run build를 실행해줘. 실행하지 못한 항목은 미확인으로 써줘. 선택하지 않은 추가 기능은 평가하지 마. 테스트 통과와 내 화면에서 직접 확인한 수행 상태는 구분해줘.
```

## P7 — 실제로 관찰한 문제 한 곳 수정

```text
내 실행 폴더는 [폴더]이고 자료 종류는 [수집본 재생/가상/본인 직접 호출]이야. 입력과 실행 순서는 [입력·순서], 기대 결과는 [기대값], 실제 결과는 [관찰값]이야. 비밀값 없는 오류 문구는 [문구]야. 이 차이를 만드는 문제 한 곳을 확인하고 수정해줘. 기존 정상 자료와 다른 기능을 유지하고 같은 입력으로 재시험해줘. 실행하지 못한 검증은 미확인으로 기록해줘.
```
