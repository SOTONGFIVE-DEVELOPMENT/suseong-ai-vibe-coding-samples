# STEP 02 Codex 요청문

## 요청

```text
data/records.json의 items를 서버 GET /api/libraries에서 읽고 표에 표시해줘. 도서관 A·B·C와 대구 수성구 2건·대구 중구 1건을 유지해. 도서관 B의 빈 주소와 null인 referenceDate는 정보 없음으로 표시해. 파일을 바꾼 뒤 새로고침해 반영되는지 확인하는 방법을 알려줘.
```

이전 단계의 복사본에서 기능을 만들어 보고 이 정상본과 비교하세요. 정상본에서 요청할 때는 먼저 "현재 구현을 읽고 이미 된 항목과 추가할 항목을 구분해줘"라고 요청합니다. 실제 개인정보·기관 내부자료·인증키는 넣지 않습니다.

## 결과 검증 요청

```text
변경된 파일을 알려줘. README의 성공 기준 각각에 대해 입력·예상 결과·실제 결과를 비교해줘. npm test와 npm run build를 실행하고 실패한 항목은 해결해줘. 실행하지 못한 검증은 미확인이라고 써줘.
```

## 오류 설명 요청

```text
내가 실행한 순서는 [순서], 예상 결과는 [기대값], 실제 결과는 [관찰값]이야. 비밀값이 없는 오류 문구는 [문구]야. 원인을 확인하고 수정해줘. 기존 정상 자료 파일을 유지하고 수정 후 같은 순서로 재시험해줘.
```
