# STEP 04 Codex 요청문

## 요청

```text
기본 sample 모드에서 data/sample-api-response.json을 외부 API 응답처럼 읽어 필수 필드와 성공 코드를 검증하고 data/records.json에 저장해줘. 화면에 교육용 API 응답이라는 출처와 sample 모드를 표시해. 잘못된 응답, 인증 오류, 시간 초과일 때는 기존 정상 파일을 유지해야 해. 키 없이 확인할 방법과 재시작한 뒤 저장됐는지 확인할 방법을 알려줘. 실제 API 호출은 live 모드를 따로 선택했을 때만 가능하게 해줘.
```

이전 단계의 복사본에서 기능을 만들어 보고 이 정상본과 비교하세요. 정상본에서 요청할 때는 먼저 "현재 구현을 읽고 이미 된 항목과 추가할 항목을 구분해줘"라고 입력합니다. 실제 개인정보, 기관 내부 자료, 인증키는 넣지 마세요.

## 결과 검증 요청

```text
변경된 파일을 알려줘. README의 성공 기준마다 입력, 예상 결과, 실제 결과를 비교해줘. npm test와 npm run build를 실행하고 실패한 항목은 해결해줘. 실행하지 못한 검증은 미확인이라고 써줘.
```

## 오류 설명 요청

```text
내가 실행한 순서는 [순서], 예상 결과는 [기대값], 실제 결과는 [관찰값]이야. 비밀값이 없는 오류 문구는 [문구]야. 원인을 확인하고 수정해줘. 기존 정상 자료 파일을 유지하고 수정 후 같은 순서로 재시험해줘.
```
