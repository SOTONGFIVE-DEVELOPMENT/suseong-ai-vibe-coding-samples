# STEP 04 Codex 요청문

## 요청

```text
기본 sample 모드에서 data/sample-api-response.json의 기록된 실제 공개 응답 3건을 읽고 검증해 data/records.json에 저장하는 기능을 만들어줘. 외부 접속이나 키 없이 동작해야 해. 원본 이름·주소·전화·기준일, recordedAt, upstreamTotalCount=242, 응답 SHA-256을 보존하고 totalCount=3 및 이 PC의 재생·저장 시각 syncedAt을 구분해. sample 재생을 현재 사용자의 실전 인증 성공이라고 표시하지 마. 잘못된 응답·시간 초과·인증 오류 연습에서는 정상 파일을 보존하고 재시작 후에도 저장 결과가 유지돼야 해. live는 사용자가 선택할 때만 서버의 비밀키로 호출해. 테스트와 빌드를 실행해.
```

이전 단계의 복사본에서 기능을 만들어 보고 이 정상본과 비교하세요. 정상본에서 요청할 때는 먼저 "현재 구현을 읽고 이미 된 항목과 추가할 항목을 구분해줘"라고 입력합니다. 실제 개인정보, 기관 내부 자료, 인증키는 넣지 마세요.

## 결과 검증 요청

```text
변경된 파일을 알려줘. README의 성공 기준마다 입력, 예상 결과, 실제 결과를 비교해줘. npm test와 npm run build를 실행하고 실패한 항목은 해결해줘. 실행하지 못한 검증은 미확인이라고 써줘.
```

## 오류 설명 요청

```text
내가 실행한 순서는 [순서], 예상 결과는 [기대값], 실제 결과는 [관찰값]이야. 비밀값이 없는 오류 문구는 [문구]야. 원인을 확인하고 수정해줘. 기존 정상 자료 파일을 유지하고 수정 후 같은 순서로 재시험해줘.
```
