# 조건 하나 변경 → 가상 업무 전이 — Codex 요청문

출발 상태: 조건 제작은 이름 검색을 마친 03 작업본의 별도 복사본에서 시작합니다. 05 정상본의 지역·유형 조건은 비교 자료입니다. 수업에서는 자신이 고른 조건 하나만 평가합니다. 가상 업무 전이는 05 ZIP의 별도 복사본을 미리 준비해 사용합니다.

## 조건 하나 변경 요청

```text
현재 이름 검색 작업본의 별도 복사본에 지역 선택 조건 하나를 추가해줘. 기존 이름 검색과 초기화는 유지하고 이름과 선택 지역을 모두 만족하는 자료만 보여줘. 실제 저장 예제에서 대구 수성구는 2건, 대구 중구는 1건, 사월+대구 수성구는 1건, 사월+대구 중구는 0건, 초기화하면 3건이어야 해. 원본 자료와 수집 근거는 보존해. 선택하지 않은 유형 조건은 이번 과제로 만들거나 평가하지 마. 변경 파일과 같은 입력으로 재시험할 순서를 알려줘.
```

유형 조건을 선택했다면 위 지역 조건과 기대값을 유형 조건의 값으로 바꾸세요. 05 정상본은 이름·지역·유형을 모두 AND로 결합하지만, 선택하지 않은 기능까지 수행 완료로 요구하지 않습니다.

## 자기 업무로 옮기기 (가상 전이 복사본에서)

README의 순서대로 `npm run prepare-transfer -- --copy`를 실행한 뒤 요청합니다.

```text
현재 자료는 별도 복사본의 가상 업무 목록이야. dataKind=synthetic과 가상 출처 표시를 유지하고 실제 기관의 출처·수집 시각·원본 건수·응답 지문을 붙이지 마. items의 이름·지역·유형을 [가상 업무 목록]에 맞게 바꾸고, [바꿀 조건 하나]만 수정해줘. 먼저 정상·0건·빈 값 또는 실패 입력의 기대값을 알려줘. 다른 기능은 유지하고 같은 입력으로 관찰 결과를 비교할 순서를 알려줘. API 가져오기 버튼은 실행하지 마.
```

## 결과 검증 요청

```text
현재 구현을 읽고 이미 된 항목과 추가할 항목을 구분해줘. README와 CHECKLIST의 해당 활동 기준마다 실행 폴더, 자료 종류, 입력, 기대 결과, 실제 결과를 비교해줘. 파일을 바꿨다면 변경 파일을 알려주고 npm test와 npm run build를 실행해줘. 실행하지 못한 항목은 미확인으로 써줘. 선택하지 않은 추가 기능은 평가하지 마. 테스트 통과와 내 화면에서 직접 확인한 수행 상태는 구분해줘.
```

## P7 — 실제로 관찰한 문제 한 곳 수정

```text
내 실행 폴더는 [폴더]이고 자료 종류는 [수집본 재생/가상/본인 직접 호출]이야. 입력과 실행 순서는 [입력·순서], 기대 결과는 [기대값], 실제 결과는 [관찰값]이야. 비밀값 없는 오류 문구는 [문구]야. 이 차이를 만드는 문제 한 곳을 확인하고 수정해줘. 기존 정상 자료와 다른 기능을 유지하고 같은 입력으로 재시험해줘. 실행하지 못한 검증은 미확인으로 기록해줘.
```
