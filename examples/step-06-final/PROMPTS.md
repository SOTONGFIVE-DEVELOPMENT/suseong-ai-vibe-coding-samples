# STEP 06 — 로컬 최종 산출물 제작 프롬프트

06 정상본은 공개 최종 앱과 비교하는 기준입니다. **05까지 만든 현재 작업본 전체를 백업하고 같은 폴더에 06을 통합**합니다. 백업 복사본에서 이어가기로 선택한 경우 CHECKLIST에 실행 폴더가 바뀐 것을 기록합니다. 이미 작성한 API·검색·저장 파일을 이어 쓰고 실제 자료와 인증키를 프롬프트에 붙이지 않습니다. 배포·가입·Cloudflare·D1은 이 과제의 완료 조건이 아닙니다.

## 06 정상본을 확인하는 프롬프트

```text
이 폴더의 README와 CHECKLIST를 읽고 로컬 최종 앱을 설명해줘. 아직 코드를 바꾸지 말아줘. 공개 화면, /api/libraries, /api/import, /api/health, data/records.json이 같은 Next.js 서버에 어떻게 연결되는지 알려줘. 실제 저장 예제3건·원본242건·원본 수집일과 이 PC재생 저장일을 구분해줘. 검증 명령과 3→1→0→3, AND검색, URL복원 입력을 알려줘. 비밀값을 읽거나 출력하지 마.
```

## 체크포인트 A — 05의 같은 프로젝트에 기능 연결

05까지 만든 현재 작업본 전체를 먼저 백업하고 같은 폴더에서 실행합니다. API 실습용 다른 폴더를 출발점으로 바꾸지 않습니다.

```text
05까지 만든 이 폴더의 현재 작업본 전체를 먼저 백업하고 같은 폴더에서 로컬 최종 산출물까지 만들 거야. README를 읽고 기존 Next.js 서버, lib/store.mjs, lib/api-source.mjs, data/records.json, /api/import를 먼저 확인해줘. 같은 앱에서 이름·지역·유형을 AND로 검색하고 출처·범위·전화·기관 기준일·저장시각을 보존해줘. 공개 최종 화면이 쓰는 name,region,type URL과 matchedCount,facets 응답 규격을 기존 검색에 연결해줘. 05의 q는 최종 name으로 전환해. 0건에서도 전체 지역·유형 선택지를 유지하고 조건 초기화·URL새로고침·뒤로가기 복원을 구현해줘. 인증키 없는 저장 응답 재생과 오류 시 기존 정상 파일 보존을 계속 사용해. 키를 읽거나 실제 API를 호출하지 마. 화면부터 바꾸지 말고 이 기능의 입력·기대·관찰 결과를 먼저 검증해줘.
```

통과 기준은 전체3, 사월1, 없는도서관0, 초기화3, 사월+수성구+작은도서관1, 사월+중구+작은도서관0입니다. 주소를 복사해 다시 열고 뒤로가기를 확인합니다.

## 체크포인트 B — 공개 최종 화면으로 완성

A의 통과를 CHECKLIST에 기록한 뒤 같은 프로젝트에서 진행합니다. 06 정상본을 비교용 폴더로 AI에 알려주세요.

```text
앞 체크포인트를 통과한 같은 프로젝트를 이어서 최종 화면으로 완성해줘. 비교용06 정상본의 public/index.html, public/app.js, src/styles.css와 그림을 기준으로 제목·검색폼·도서관목록·자료안내·모바일화면을 맞춰줘. 기존 JSON저장·API실습·AND검색을 이 화면에 연결해. 06처럼 최종HTML을 app/route.js에서 표시한다면 기존 app/page.js와 충돌하지 않도록 바꾸고, 화면클라이언트의 name 및 matchedCount·facets 규격을 확인해. sample의 syncedAt은 이 PC재생·저장 시각이고 recordedAt은 원본 수집 시각이므로 구분해 표시해. 연락처는 tel링크로 만들어줘. 키 없이 로컬127.0.0.1에서 실행하고 배포는 추가하지 마. 최종 앱의 다시 조회는 저장 자료만 조회하며 API저장 검증은 같은 서버의 /api/import를 사용하는 별도 로컬 명령으로 남겨줘. 변경파일과 npm test·npm run build 결과를 알려줘.
```

## 체크포인트 C — 최종 검증과 재개 기록

```text
CHECKLIST의 최종검증을 한 항목씩 안내해줘. 3→1→0→3, 이름·지역·유형AND, 0건에서선택지, URL새로고침·재열기·뒤로가기, 전화링크, 주소·기준일·출처·범위·시각, 저장응답재생, 모의실패 시 정상파일보존, 서버중단 후 같은폴더 재개를 확인하고 기대값과 관찰값을 비교해줘. npm test와 npm run build도 실행해줘. 실전API성공은 내가 직접선택하지 않았다면 미실행으로 기록해. 미완성은 완료로 표시하지 말고 같은CHECKLIST에 다음할일과 재개명령을 남겨줘. 인증키를 읽거나 출력하지 마.
```

## 중단할 때 사용하는 프롬프트

```text
현재 폴더의 CHECKLIST에 실행폴더, 마지막통과체크포인트, 검증입력과 관찰결과, 변경파일, 미해결오류, 다음할일, 재개명령을 적어줘. 2일차가 끝나도 이 프로젝트에서 최종산출물까지 이어갈 수 있게 해줘. 테스트나 화면에서 확인하지 않은 것은 미확인으로 적어. 실제기관자료와 비밀값은 수정하거나 복제하지 마.
```
