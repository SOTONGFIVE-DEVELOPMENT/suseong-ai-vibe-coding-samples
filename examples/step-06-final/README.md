# STEP 06 — 로컬 최종 산출물 통합과 재개

05의 Next.js 서버·JSON 저장·API를 이어서 **공개 최종 산출물과 같은 화면과 동작**을 본인 PC에서 완성합니다. 공개 배포는 완료 조건이 아닙니다. 이 폴더는 앞 단계나 Cloudflare 계정 없이 독립 실행하는 정상본입니다.

## 실행

Node.js **22.x**와 npm이 필요합니다. macOS 터미널 또는 Windows PowerShell에서 **이 파일과 package.json이 있는 폴더**를 엽니다.

```sh
node --version
npm --version
npm ci
npm run dev
```

[로컬 최종 앱](http://127.0.0.1:3000)을 엽니다. 포트가 사용 중이면 Ctrl+C로 중지하고 `npm run dev -- --port 3001`로 시작한 뒤 `http://127.0.0.1:3001`을 여세요. Windows의 `npm.ps1` 실행 정책 오류는 같은 명령의 `npm`을 `npm.cmd`로 바꾸면 됩니다. 전역 실행 정책은 변경하지 마세요. 서버는 본인 PC의 127.0.0.1에서만 실행합니다.

## 최종 완료 기준

- 같은 최종 화면의 제목·책 그림·검색 폼·목록·자료 안내가 표시됩니다.
- 실제 저장 예제 **전체 3 → 사월 1 → 없는도서관 0 → 초기화 3**을 확인합니다.
- 이름 `사월` + 지역 `대구 수성구` + 유형 `작은도서관`은 1건이며, 지역을 `대구 중구`로 바꾸면 0건입니다. 조건은 AND입니다.
- 0건에서도 지역·유형의 전체 선택지는 유지됩니다.
- 검색 후 주소의 `name`, `region`, `type`을 확인하고 새로고침·주소 다시 열기·뒤로가기로 같은 조건과 결과를 복원합니다.
- 전화번호는 전화 링크이며, 이름·주소·전화·기관 기준일·자료 출처·저장 범위·저장 건수는 원본값과 일치합니다.
- 저장 응답 재생에 성공하고 오류를 재현하면 기존 정상 파일이 유지됩니다. 화면의 다시 조회는 저장 파일만 읽습니다.

키 없는 정상본의 자료는 실제 공공 API 응답에서 선정한 도서관 3곳입니다. 원본은 **2026-10-04 19:17:37 한국 시간에 수집한 242건**, 실습 자료는 그중 선정한 **3건**입니다. 목록 건수가 공개 최종 앱과 같아야 완료인 것은 아닙니다. 기본 실습은 외부 API에 접속하지 않으며 본인 인증키의 실전 호출 성공을 뜻하지 않습니다.

## 이어 만들기와 중단·재개

`PROMPTS.md`의 **05까지 만든 현재 작업본 전체 백업 → 같은 폴더에 기능 연결 → 최종 화면 → 검증** 순서로 진행합니다. 정상본 06은 비교·복구 기준이고, 본인이 만드는 프로젝트는 현재 작업 폴더 하나를 계속 사용합니다. API 실습용과 검색 앱을 다시 분리하지 마세요. 전체 백업 복사본에서 작업을 이어가기로 선택했다면 CHECKLIST에 바뀐 실행 폴더를 기록합니다. 실행 중인 서버는 수정 전 Ctrl+C로 중지합니다.

2일차 종료 시 미완성이어도 `CHECKLIST.md`에 실행 폴더·현재 체크포인트·완료 입력과 결과·다음 할 일·실패한 검증을 기록하고 Ctrl+C로 서버를 중지합니다. 재개할 때 그 폴더에서 `npm run dev`로 시작해 마지막 통과 입력을 다시 확인하고 다음 체크포인트로 진행합니다. 설치와 작성이 완료된 같은 폴더에서는 다시 ZIP을 풀거나 파일을 덮어쓸 필요가 없습니다. 개발 서버를 중지해도 `data/records.json`의 저장 자료는 유지됩니다.

화면을 맞추기 전에 이름·지역·유형·URL 복원·출처 보존을 확인하세요. 중간 기능이 실패하면 마지막 통과 지점을 고쳐야 다음 단계로 갑니다. `npm test`와 `npm run build`가 통과한 뒤에도 CHECKLIST의 화면 검증을 직접 수행합니다.

## 연결되는 파일

| 기능 | 최종 단계 파일 | 05에서 이어 쓰는 것 |
|---|---|---|
| 서버·자료 저장 | `lib/store.mjs`, `data/records.json` | JSON 검증·원자적 저장·같은 자료 파일 |
| 외부 API·저장 응답 | `lib/api-source.mjs`, `app/api/import/route.js` | sample/live 분리·전체 응답 검증·실패 시 보존 |
| 이름·지역·유형 검색 | `lib/filter.mjs`, `lib/final-response.mjs`, `app/api/libraries/route.js` | 기존 AND 검색에 최종 응답 규격 연결 |
| 최종 화면 | `public/index.html`, `public/app.js`, `src/styles.css`, `app/route.js` | 기존 API를 같은 서버에서 사용 |
| 저장·오류 연습 | `scripts/import-data.mjs` | 동일 `/api/import`로 저장 요청 |

05의 이름 검색 URL은 `q`이고 최종 화면은 **`name`**을 사용합니다. `lib/final-response.mjs`가 `name`을 기존 `filterRecords`의 `query`에 연결합니다. GET 응답은 `count` 대신 **`matchedCount`**와 전체 저장 자료의 **`facets.regions/types`**를 제공합니다. 데이터 구조와 원본 자료는 변경하지 않습니다. 이전 `?q=사월` 주소는 최종 단계에서 `?name=사월`로 바꿉니다.

`public/index.html`과 그림은 공개 최종 앱과 같습니다. 반응형 스타일은 같은 원본을 사용하며 로컬의 긴 자료 출처가 모바일 폭을 넘치지 않도록 줄바꿈만 보강했습니다. `public/app.js`도 같은 동작을 사용하되 sample의 시각은 **이 PC 재생·저장**과 **원본 수집**으로 구분해 표시합니다. `public/styles.css`는 실행·빌드 때 `src/styles.css`에서 만들며 수정할 스타일 원본은 `src/styles.css`입니다. 최종 화면에는 관리용 저장 버튼을 추가하지 않고 아래 로컬 명령으로 같은 서버의 저장 API를 검증합니다.

## 같은 앱에서 자료 저장과 실패 검증

서버를 실행한 채 두 번째 터미널에서 같은 폴더를 엽니다. 기본 `DATA_MODE=sample`에서는 키 없이 저장된 응답을 재생합니다.

```sh
npm run import-data
npm run import-data -- --exercise timeout
npm run import-data -- --exercise auth
npm run import-data -- --exercise malformed
```

3001번 포트로 실행했다면 각 명령 뒤에 `--port 3001`을 추가하세요. 성공 뒤 화면의 **다시 조회**를 눌러 3건과 갱신된 로컬 재생·저장 시각을 확인합니다. `recordedAt`은 원본 수집 시각이고 `syncedAt`만 이 PC에서 재생·저장한 시각으로 바뀝니다. 세 오류는 **교육용 모의 실패**입니다. 각 실패 전후 `data/records.json`을 비교하고 목록·출처·시각이 유지되는지 확인합니다.

실전 호출은 선택 활동입니다. 본인 키의 승인이 완료된 경우 `.env.example`을 `.env.local`로 복사하고 편집기에서 `DATA_MODE=live`와 `DATA_GO_KR_SERVICE_KEY`를 설정한 뒤 서버를 재시작합니다. 위 성공 명령을 실행하면 같은 서버가 실제 API의 대구광역시 전체 페이지를 검증해 저장합니다. 정확히 같은 항목은 중복 제거하며 원본 전체 건수와 저장 건수를 구분합니다. 실전 자료에는 교육용 3→1→0→3 기준을 적용하지 않습니다. live 모의 오류 명령은 실전 호출을 하지 않고 거부합니다.

키는 `.env.local`의 서버에서만 읽습니다. 키를 AI 대화·화면 캡처·로그·GitHub에 넣거나 `NEXT_PUBLIC_` 변수로 만들지 마세요. [API 명세](docs/api-spec.md)와 [저장 응답 구조](api-response.sample.json)를 먼저 확인하세요. 이 프로젝트의 live 어댑터 검증은 인증키 없는 모의 응답으로 수행했습니다.

## 검증과 복구

서버를 Ctrl+C로 중지한 뒤 실행합니다.

```sh
npm test
npm run build
npm run start
```

빌드한 정상본도 같은 로컬 주소에서 확인합니다. 초기 실제 저장 예제로 돌아가려면 서버를 중지하고 `.env.local`이 있다면 `DATA_MODE=sample`로 바꾼 뒤 `npm run reset-data`를 실행합니다. 현재 파일을 `data/records.backup.<시각>.json`으로 보존하고 초기 3건을 복구합니다. 다시 서버를 시작하세요. `records.seed.json`과 `sample-api-response.json`은 복구 기준이므로 원본값을 바꾸지 않습니다.

자기 업무의 가상 자료 전이는 05의 **별도 복사본**에서 합니다. 06은 실제 저장 예제 또는 실제 API 자료의 최종 앱 비교 단계입니다. 실제 도서관의 빈 값·주소를 가상 연습을 위해 변경하지 마세요. 설치가 실패하면 npm registry 연결을 확인하고 비밀값이 없는 오류만 보조강사에게 보여 주세요.
